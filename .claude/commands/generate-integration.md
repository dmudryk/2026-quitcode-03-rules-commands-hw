# Generate integration

**Ціль:** $ARGUMENTS
(Якщо в рядку вище немає назви сервісу — ціль вказана в повідомленні одразу після назви
команди. Немає й там — спитай і зупинись.)

## Кроки

1. Прочитай взірець — `app/src/integrations/slack-notify.ts` і його тест — та реєстр
   `app/src/integrations/index.ts`. Форму модуля, контракт і напрям залежностей бери з
   `.claude/rules/architecture.md`, конвенції — з `.claude/rules/conventions.md`.
2. Визнач ім'я в kebab-case (`<сервіс>-<дія>`, напр. `hubspot-contact`) і узгодь його
   з іменем файлу та полем `name`. Визнач `requiredEnv` — **лише імена** змінних.
3. Визнач, чи це система **сповіщення** чи система **обліку**: від цього залежить, які
   поля ліда взагалі можна передавати (див. правило мінімізації даних у конвенціях).
   Якщо сервіс неоднозначний — вважай його системою сповіщення.
4. Створи рівно три зміни:
   - `app/src/integrations/<kebab-name>.ts` — об'єкт типу `Integration`;
   - `app/src/integrations/<kebab-name>.test.ts` — три випадки: успішна відправка
     (перевірити URL і тіло), відсутня змінна середовища, помилка зовнішньої системи;
   - один рядок у `app/src/integrations/index.ts`.
   Нічого більше: ні нових тек, ні змін у `core/`, ні залежностей у `package.json`.
5. Якщо для сервісу потрібен експорт, якого в публічному API ядра немає (інший метод
   HTTP, інший тип), — **не додавай його в ядро і не обходь ядро власним кодом**:
   зупинись за правилом `.claude/rules/do-not-touch.md`.
6. Перевір:
   ```bash
   cd app && npm test && npm run typecheck && npm run check:rules
   ```
7. Покажи підсумок: створені файли, `name`, `requiredEnv`, які поля ліда передаються і
   куди, числа трьох перевірок.

## Acceptance criteria

- [ ] Створено рівно два нових файли + один рядок у `integrations/index.ts`
      (`git status --short` це підтверджує).
- [ ] `name` інтеграції збігається з іменем файлу, обидва в kebab-case.
- [ ] `send()` повертає `Promise<Result<void>>` і не кидає винятків.
- [ ] У тестах немає реальної мережі; є всі три випадки.
- [ ] `npm test` зелений, `typecheck` чистий, `check:rules` — **без нових** порушень
      (`TOTAL` не виріс).
- [ ] У сповіщення не передаються `lead.email` і `lead.phone`.

## Stop

Перед запуском покажи, що саме створюватимеш: імена файлів, `name`, `requiredEnv`,
перелік полів ліда в запиті — і лише після цього пиши код. Якщо потрібна зміна в
захищеній зоні або нова залежність — зупинись, опиши потребу й чекай підтвердження.
